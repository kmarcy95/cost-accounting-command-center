- **What it is:** AI-assisted manufacturing cost accounting web app — "everything a consultant needs stepping into a cost accounting role at a manufacturer." Built 2026-06-04 (brainstorm → plan → TDD → deploy). **18 modules.**
- **Multi-plant group (merged from Perplexity "Cost Terminal"):** seed is **Keystone Industrial Group** — 4 plants / 5 customers / 4 products / 5 periods, with a deterministic generated **fact table** (`SEED.facts`, 400 rows) + `transactions` (subledger) + `ledger` (GL) + `budget`. **Global Plant+Period filter** lives in `store.getFilter()/setFilter()` (topbar `#globalFilter`, built in `app.js buildGlobalFilter`) and slices the group modules. `engines/cube-engine.js` (filter/aggregate/pivot/series/topN) is tested. Group views: `executive-overview` (landing), `profitability-cube` (pivot), `budget-actual`, `inventory-subledger`, `cost-ledger`. The original single-plant engine modules (variance/reserve/ABC/CVP/journal/capacity) still run on the canonical `standardCosting`/`items` inputs.
- **UX features:** dark "terminal" theme toggle (`CACC.toggleTheme`, persisted `cacc.theme`); Ctrl/⌘+K command palette + 1–9 quick-jump; live metrics ticker; sortable + CSV-export grids (`CACC.tableTools.makeSortable`/`exportButton`); drill-down modals (`CACC.ui.modal`/`itemDetail`, `CACC.varianceDrill`); clickable charts via `CACC.chartClick`. Chart palette is theme-aware in `CACC.chartTheme()`.
- **Stack:** Vanilla JS, **no framework, no build**. UMD/IIFE modules attach to a single `window.CACC` namespace. Chart.js 4.4.1 via CDN (**SRI-pinned** `sha384-9nhcz…urn4` + `crossorigin`). Fluent / Dynamics 365 **light** theme (accent `#0f6cbd`, slate ramp, Segoe UI, tabular-nums on data).
- **Architecture:**
  - `engines/` — **pure, DOM-free, unit-tested** math (**36 tests**): `cost-variance-engine.js` (copied from Business-Landing-Page, sign convention **positive = Unfavorable**), `product-costing-engine.js` (job-order / weighted-avg process / ABC), `inventory-engine.js` (FIFO/LIFO/WAC valuation + RM→WIP→FG→COGS cost flow + OH absorption), `inventory-reserve-engine.js` (**multi-item LCNRV write-down + excess & obsolete reserve**, aging + demand-coverage driven; `analyzePortfolio`), `journal-entries-engine.js` (balanced standard-cost JEs, variances isolated at incurrence), `cvp-engine.js`, `diagnostic-engine.js` (weighted 5-dimension health score).
  - `assets/` — `seed-data.js` (**Stratton Manufacturing Co.** demo dataset), `store.js` (LS helper + state + `fmt`/`dom` utils), `model.js` (maps stored data → engine inputs; single derive layer reused by views + AI), `app.js` (icons, `CACC.ui` builders, router, chart lifecycle, `CACC.boot`), `app.css`.
  - `ai/` — `insights.js` (deterministic, always-on analyst narratives + `buildPrompt`), `claude-client.js` (optional BYO-key live Claude via direct browser fetch w/ `anthropic-dangerous-direct-browser-access`; graceful fallback).
  - `views/` — one render module per screen (dashboard, **trends**, standardCosting, productCosting, inventory, **inventoryReserve**, cvp, **itemMaster**, **journal**, diagnostic, settings); register into `CACC.views`. Dashboard is a dense full-cockpit (2 KPI rows, trend chart, alerts panel, donut, top-reserve, recent JEs). `trends` = 6-month time series from seed `history`; `model.alerts()` derives cross-module alerts. Content max-width 1640px centered. Drill-down via `CACC.ui.modal` + `CACC.ui.itemDetail` (SKU detail: LCNRV + E&O build + BOM roll-up). Terminal-style extras in `app.js`: `CACC.openPalette()` (Ctrl/⌘+K command palette), digit `1–9` quick-jump, and a topbar metrics `#ticker` refreshed by `updateTicker()` on each navigate.
  - `tests/` — `node --test tests/*.test.js` (**26 tests**; glob form required on Node 24/Win).
- **AI = hybrid:** deterministic insights work fully offline; paste an Anthropic key in **Settings** → panels upgrade to live Claude. Key stored only in `localStorage`, sent only to api.anthropic.com.
